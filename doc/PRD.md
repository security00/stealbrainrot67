# Steal Brainrot 67 PRD

Version: 2.0
Last updated: 2026-06-14
Product type: game SEO site
Primary market: English-speaking Roblox players and search users

## Objective

Recover and grow organic traffic around Steal Brainrot, 67, Lucky Blocks, item stats, and practical player guides while keeping the site lightweight enough for fast static deployment.

## Current Position

- GSC baseline before restart: 93 clicks, 4.05K impressions, 2.3% CTR, and average position 16.5 over the latest 3-month window shared on 2026-06-14.
- Current ranking demand is mostly around 67 variants, but Google Trends shows stronger demand for the broader `steal brainrot` topic.
- The original iframe source stopped working and has been replaced with `https://yoplay.io/steal-a-brainrot.embed`.

## Target Users

- Roblox players searching for a quick playable Steal Brainrot browser entry.
- Players trying to understand item 67, Lucky Blocks, and item value or spawn information.
- Search users comparing current community-reported information before opening Roblox.

## Core User Jobs

- Play or preview a Steal Brainrot-style browser embed quickly.
- Learn what item 67 is and how it is commonly discussed.
- Find Lucky Blocks information without outdated event claims.
- Read concise guides that are dated and do not overclaim unsupported facts.

## Information Architecture

- `/`: homepage and game embed.
- `/steal-brainrot`: main topic hub for the broader keyword gap.
- `/lucky-blocks`: evergreen Lucky Blocks hub.
- `/guides/how-to-get-67`: guide page for 67 acquisition and context.
- `/items`: item index.
- `/items/67`: dedicated 67 item page.

## Content Accuracy Rules

- Prefer official Roblox or developer sources when available.
- If information comes from community pages, videos, or observed gameplay, label it as community-reported or currently observed.
- Avoid publishing fake codes, event schedules, drop rates, or item values unless the source is current and credible.
- Add dates to pages where freshness matters.

## Success Metrics

- GSC starts showing impressions for `steal brainrot`.
- Homepage and `/steal-brainrot` impressions increase within 2 to 4 weeks after indexing.
- CTR improves on pages with clear titles and descriptions.
- New long-tail queries appear around Lucky Blocks, item 67, and "how to get" topics.
- Static build stays fast and `npm audit` remains clean.
